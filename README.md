# RouteGo Cab Booking

React + Vite cab booking website.

## Requirements
Node.js 18 or newer. Internet is needed for the first npm install.

## Run
1. Extract the ZIP.
2. Open the extracted folder in VS Code.
3. Open Terminal in that folder.
4. Run `npm install` and then `npm run dev`.
5. Open the localhost URL printed by Vite (usually http://localhost:5173).

Windows: double-click `start.bat`.

## Features
Responsive UI, route selection, pickup/drop swap, one-way/round-trip fare estimate, fleet filters, booking modal, validation, passenger counter, booking ID, localStorage, WhatsApp/call links, services, pricing, popular routes, and mobile navigation.

This is a frontend demo; bookings are saved locally and are not sent to a real backend.
